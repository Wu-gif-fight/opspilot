# 安全合规

## 应用安全

- 输入校验：所有外部输入都要做参数校验，防止 SQL 注入和 XSS。
- 认证鉴权：统一身份认证，接口按角色做最小权限控制。
- 敏感数据：密码使用加盐哈希，密钥走密钥管理服务，日志脱敏。

## 数据安全

- 用户敏感信息（手机号、地址）存储加密，展示脱敏。
- 数据库访问走最小权限账号，禁止应用使用超级管理员连接。
- 定期审计数据访问日志，发现异常及时处理。

## 合规要求

- 电商平台涉及支付，需符合支付合规和等保要求。
- 日志保留期限满足审计要求，敏感日志单独管理。
- 涉及用户数据跨境或共享时，需评估合规风险。

## 应急与演练

- 定期做安全扫描和渗透测试，及时修复高危漏洞。
- 制定数据泄露应急预案，明确上报和通知流程。
