# API 网关与服务治理

## 网关职责

- 统一入口：鉴权、限流、路由、协议转换。
- 统一出口：日志、监控、链路追踪、灰度发布。

## 服务治理

- 服务发现：注册中心维护实例列表，剔除不健康实例。
- 负载均衡：优先使用一致性哈希或加权轮询，减少热点。
- 熔断降级：下游连续失败时快速失败，避免雪崩。
- 限流：对核心接口配置令牌桶或滑动窗口限流。

## 接口规范

- 统一错误码和响应结构，方便前端和调用方处理。
- 对外接口要做幂等，尤其支付、下单等写操作。
- 接口要做超时和重试控制，重试要保证幂等。

## 常见问题

- 网关超时：检查上游服务延迟，调整超时与重试策略。
- 熔断频繁触发：定位下游慢原因，而不是一味调大阈值。
