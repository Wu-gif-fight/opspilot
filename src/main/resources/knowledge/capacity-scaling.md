# 容量与扩容

## 容量评估

- 结合大促和流量峰值做压测，确认单实例 QPS 上限。
- 关注数据库连接数、线程池、内存等瓶颈资源。
- 定期做容量规划，预留 30% 以上冗余。

## 扩容方式

- 水平扩容：增加实例数量，配合负载均衡分摊流量。
- 垂直扩容：提升单机规格，适用于数据库等有状态服务。
- 弹性伸缩：按 CPU 或 QPS 指标自动扩缩容，应对流量洪峰。

## 缓存与削峰

- 热点数据放缓存，减少数据库压力。
- 用消息队列削峰填谷，平滑突发流量。
- 缓存要设置合理过期时间和淘汰策略，防止缓存雪崩。

## 雪崩与穿透

- 缓存雪崩：过期时间加随机抖动，避免同一时刻大量失效。
- 缓存穿透：用布隆过滤器或空值缓存兜底。
- 缓存击穿：热点 key 用互斥锁或逻辑过期保护。
